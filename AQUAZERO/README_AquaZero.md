## 🧩 El puzzle
Las tuberías están desordenadas. Tu trabajo es **rotar cada pieza** hasta construir una ruta continua desde la nube hasta el tanque.

### 🔄 Pasos
1. Selecciona una tubería.
2. Usa `↶ GIRAR` o `GIRAR ↷`.
3. Comprueba que las conexiones coincidan.
4. Cierra todas las posibles fugas.
5. Completa el circuito y observa el agua fluir.

## 💦 Objetivo
**Nube ☁️ → Tuberías 🧩 → Tanque 🚰**

Una conexión incorrecta puede provocar una fuga y evitar que el agua llegue al destino.

## 🖱️ Controles
Universal: **clic o toque directo** sobre las piezas y botones de giro.
