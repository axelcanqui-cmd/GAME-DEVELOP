## 🎯 Objetivo
Controla tu nave, identifica el resultado correcto y atrapa la respuesta antes de perderla. Cada error puede costarte una vida.

## 🎮 Cómo jugar
1. Observa la operación que aparece arriba.
2. Busca entre las burbujas la respuesta correcta.
3. Mueve la nave con `A/D` o `⬅️/➡️`.
4. Atrapa la respuesta correcta.
5. Llega a **50 puntos** para completar la misión.

### 🕹️ Controles
- 💻 **PC:** `A` / `D` o `⬅️` / `➡️`
- 📱 **Móvil:** botones táctiles `◀` y `▶`

## ❤️ Sistema de vidas
**3 vidas → 0 vidas = GAME OVER.**
Pierdes una vida si chocas con una respuesta incorrecta o dejas caer la correcta.

## 🧠 ¿Qué se practica?
⚡ Cálculo mental · 🎯 Atención · 🧩 Resolución rápida · 🧮 Operaciones básicas
